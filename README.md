# EduMIS Pro – Student Management Information System

EduMIS Pro is an interactive web-based Student Management Information System developed using Python Flask. The project demonstrates how different aspects of Management Information Systems can be integrated into a single academic management platform.

The system collects and manages student information and uses the available data for academic analysis, decision support, executive-level reporting, communication management, and academic resource monitoring.

## Key Modules

- Student Management
- Executive Support System (ESS)
- Decision Support System (DSS)
- Communication Management (CRM)
- Academic Supply Chain Management (SCM)

## Main Features

- Add and manage student records
- Search and filter students
- Store marks and attendance information
- Automatic student performance categorization
- Academic risk-score calculation
- Student performance overview
- Executive dashboard with KPIs
- Marks and category distribution analytics
- Identification of students requiring intervention
- Recommended intervention actions
- Course capacity monitoring
- Academic resource availability tracking
- Active enrolment tracking
- Interactive web-based dashboard

## Student Categorization

Students are automatically categorized based on their marks and attendance:

- **Excellent** – Marks ≥ 75% AND Attendance ≥ 80%
- **Average** – Marks ≥ 50% AND Attendance ≥ 60%
- **At Risk** – Below Average thresholds
- **Invalid** – Values outside the 0–100 range

## Technology Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Data processing and analytics
- Web-based dashboard

## Project Objective

The objective of EduMIS Pro is to demonstrate how student data can be transformed into useful management information and decision-support insights. Instead of simply storing student records, the system uses the collected information to generate performance indicators, identify academic risks, support interventions, and provide management-level insights.

## Academic Context

This project was developed as a practical implementation of Management Information System concepts and demonstrates the integration of multiple information-system components into a student management environment.
